# Enhancement Roadmap

Future features and improvements planned for the Farm Management System.

> Priority: P0 = Critical, P1 = High, P2 = Medium, P3 = Low

---

## Phase 1: Core Improvements (Weeks 1-4)

### Dashboard Rewrite
- [ ] Real-time dashboard widgets (not hardcoded)
- [ ] Weather integration widget
- [ ] Quick-action buttons
- [ ] Customizable widget layout

### Task Management
- [ ] Task dependencies and subtasks
- [ ] Recurring tasks
- [ ] Task templates
- [ ] Bulk task assignment

### Worker Attendance
- [ ] Geofenced clock-in/out
- [ ] Photo verification
- [ ] Overtime calculation
- [ ] Attendance reports

---

## Phase 2: Data & Analytics (Weeks 5-8)

### Charting & Visualization
- [ ] Production trend charts (Recharts)
- [ ] Financial charts (revenue vs expenses)
- [ ] Crop yield comparison charts
- [ ] Livestock growth curves

### Crop Calendar
- [ ] Visual planting/harvest calendar
- [ ] Stage-based reminders
- [ ] Weather-aware scheduling
- [ ] Historical crop cycle comparison

### Cost Analysis
- [ ] Cost per crop cycle
- [ ] Cost per livestock batch
- [ ] Profitability by farm/field
- [ ] Expense categorization and trends

## Notes

- Many backend endpoints referenced in this roadmap are aspirational and do not exist yet
- Some features may require new services (e.g., `task-service`, `inventory-service`)
- Priorities may shift based on user feedback and business needs
- Each phase should include testing, documentation, and deployment
